# Glossary

| Term | Project meaning |
|---|---|
| Owner | Role managing finances and configuration, with read-only clinical access. |
| Doctor | Treating dentist with clinical responsibilities and access to their own financial activity. |
| Staff | Operational role handling registration, scheduling, payments, and limited treatment coordination. |
| Patient file | Patient details, shared medical information, clinical history, and attachments. |
| Treatment plan / TTT plan | A doctor's proposed collection of procedures for a patient. |
| Acceptance | Patient agreement recorded per procedure; creates no debt. |
| Planned procedure | Accepted procedure that has not started and is not owed. |
| In-progress procedure | Started treatment whose price is owed, less allocated payments. |
| Done procedure | Completed treatment; unpaid amounts remain debt. |
| Stopped procedure | Interrupted treatment retaining its unpaid balance and capable of resuming. |
| Standalone procedure | A procedure outside a treatment plan. |
| Appointment | Reserved time with a doctor. |
| Visit | Actual attendance and care session, with actual timing and clinical notes. |
| Arrived | Attendance marker that opens the assigned doctor's initial clinical access. |
| Clinical note | Doctor-authored record that locks after the visit. |
| Amendment | Dated correction or addition preserving the original clinical note. |
| Shared medical information | Allergies and conditions editable by authorized treating doctors with attribution. |
| Patient debt | Unpaid obligation; planned treatment is excluded. |
| Opening debt | Historical patient debt linked to a doctor without a procedure. |
| Payment | Money received by cash or manually verified mobile money. |
| Allocation | Assignment of money to a procedure, consultation, or opening debt. |
| Patient credit | Excess money associated with the patient and original doctor. |
| Advance / down payment | Money assigned before treatment starts; detailed accounting presentation remains unresolved. |
| Refund | Money returned to the patient, with reason and history. |
| Correction / void | Correction or reversal of an erroneous payment record, distinct from a refund. |
| Receipt | Document recording a payment and remaining balance. |
| Invoice | Optional document listing completed, fully paid procedures. |
| Consultation fee | Consultation charge that contributes to doctor percentage earnings. |
| Gross basis | Received payments before deductible costs. |
| After-cost basis | Received payments minus deductible costs, before applying the percentage. |
| Doctor earnings | Compensation earned, separate from compensation actually paid. |
| Payout | Actual payment of compensation to a doctor or staff member. |
| Cost carry-forward | Uncovered procedure costs deducted against later receipts for that procedure. |
| Currency label | One clinic-wide monetary unit without conversion. |
| Read-only offline | Previously loaded information remains readable; changes require connectivity. |
